# Contribuer au projet

## Association C.O.R.S.I.C.A.

Ce projet est porté par l'association loi 1901 **C.O.R.S.I.C.A.** (Collectif Ouvert pour la
Résilience et la Souveraineté Informatique des Citoyens et Administrations). Non, en fait c'est
l'association Corse Organisant la Réunion Sur Internet de Compétences Autonomes. Crée par Jean
Hugues Noël Robert fin 1995, 30 ans déjà.

## Comment contribuer ?

### 💻 Code

Attention, le code est extrêmement jeune et bouge encore beaucoup.

1. Fork le dépôt
2. Créez une branche (`git checkout -b feature/ma-fonctionnalite`)
3. Committez vos changements (`git commit -m 'Ajoute une fonctionnalité'`)
4. Push sur la branche (`git push origin feature/ma-fonctionnalite`)
5. Ouvrez une Pull Request

### 📝 Documentation

- Guides utilisateurs
- Traductions
- Tutoriels vidéo

### 🧪 Tests

- Beta-testeurs bienvenus
- Signalement de bugs via GitHub Issues
